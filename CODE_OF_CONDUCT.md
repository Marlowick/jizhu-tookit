# Code of Conduct

This project follows the spirit of the Contributor Covenant 2.1.

Be respectful, assume good intent, and keep discussion technical. Harassment, discrimination, doxxing, and publishing private data or credentials are not acceptable.

Maintainers may remove comments, close issues, or block participants for behavior that makes collaboration unsafe.

To report a conduct issue privately, use the repository’s private vulnerability reporting channel if it is security-sensitive, or contact the maintainer through GitHub. Do not publish personal information in a public issue.
